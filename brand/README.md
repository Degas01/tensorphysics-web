# TensorPhysics brand

Official identity, adopted 22 November 2026. Every file here is generated by `make_brand.py`; change the geometry there, never by hand.

## The mark

A heavy **T** whose crossbar is cut from its stem by a measured gap.

- **Crossbar (cyan):** the model, what the simulation says.
- **Stem (signal white):** the machine, what the hardware does.
- **The gap:** the distance between them. Measuring that gap is what TensorPhysics does.
- **Chamfer** on the stem's foot: a machined edge. It's a part, not an icon.

Two shapes, no gradients, no glow. It must read at 16 px.

Geometry (64-unit grid): crossbar `M6 8H58V22H6Z`, stem `M22 26H42V50L36 56H22Z`. Favicon variant (32-unit grid) widens the gap so it survives at 16 px.

## Colours

| Role | Hex |
|---|---|
| Void (background) | `#040507` |
| Instrument panel | `#0A0C10` |
| Signal white | `#F4F6F8` |
| Safety cyan: holds, verified, the model | `#00E5FF` |
| Thermal orange: breaks, `u > 1.00` | `#FF4D00` |

Cyan and orange are status colours. Don't use orange for decoration.

## Type

- Wordmark: Space Grotesk 600, uppercase, +80 tracking, converted to outlines.
- Headlines: Space Grotesk. Body: Inter. Telemetry, labels, numbers: JetBrains Mono.

## Rules

- Clear space around the mark: at least the crossbar height on every side.
- Minimum size: mark 16 px, lockup 18 px tall.
- Don't recolour, rotate, outline, add effects, or close the gap.
- In one colour, both parts take the same colour; the gap stays.

## Regenerate

```bash
pip install fonttools brotli
python3 brand/make_brand.py node_modules/@fontsource-variable/space-grotesk/files/space-grotesk-latin-wght-normal.woff2 brand/out
```

Note: this is the company's adopted identity. Registering it as a trademark (UK IPO) is a separate step, and a search for similar marks should come first.
